# 3Q

맥북 네오에서 실행하는 TQQQ·SQQQ 운영 도구입니다. KIS 실계좌 모니터링과 명시적으로 확인한 지정가 주문, 별도 개발용 모의매매를 지원합니다. 초기 기획과 연구 항목은 [3Q_PROJECT.md](3Q_PROJECT.md)에 있습니다.

## 맥북 네오 서버와 휴대폰 웹앱

맥북 네오에서 3Q 서버를 실행합니다. **맥 관리자 화면**은 맥의 브라우저에서 `http://127.0.0.1:8033`으로 엽니다. **휴대폰 화면**은 Tailscale의 비공개 HTTPS 주소에서 열고 홈 화면에 설치할 수 있습니다. 두 화면은 같은 계좌와 데이터를 사용합니다.

### 처음 연결

1. 맥과 휴대폰에 Tailscale을 설치하고 같은 비공개 네트워크에 연결합니다. 관리자 콘솔에서 MagicDNS와 HTTPS 인증서를 활성화합니다.
2. 맥에서 `tailscale serve --bg http://127.0.0.1:8034`를 실행하고 `tailscale serve status`에서 표시한 `https://…ts.net` 주소를 확인합니다. Serve의 대상으로 관리자 포트 8033을 등록하지 마세요.
3. GitHub의 비공개 저장소에 접근할 수 있는 맥에서 Python 3.11 이상을 설치하고 서버를 설치합니다.

```bash
git clone https://github.com/chjj0688/3Q.git ~/Projects/3Q
cd ~/Projects/3Q
bash scripts/install-macos.sh vX.Y.Z https://맥의-실제-주소.ts.net
```

`vX.Y.Z`는 GitHub에 게시된 버전으로 바꿉니다. 설치 명령은 macOS 로그인 시 서버를 시작하는 LaunchAgent를 등록합니다. 맥의 로그인 세션과 Tailscale 연결을 유지하고, 미국 장중 모니터링에는 자동 절전을 끄세요. 관리자 화면에서 서버를 수동 종료했다면 맥 터미널에서 `launchctl kickstart gui/$(id -u)/com.threeq.server`로 다시 시작할 수 있습니다.

4. 맥의 관리자 화면에서 **내 설정 → 휴대폰 패스키**를 열고 **소유자** 또는 **지인 · 시세 보기**를 선택해 등록 코드를 발급합니다. 휴대폰 브라우저에서 HTTPS 주소를 열고 **이 휴대폰에 처음 등록**을 선택해 5분 안에 코드를 입력합니다. 등록 후 같은 주소에서 패스키로 로그인합니다.
5. Android에서는 Chrome 메뉴의 **홈 화면에 추가** 또는 **앱 설치**를 사용합니다. iPhone에서는 Safari의 **공유 → 홈 화면에 추가**를 사용합니다. 설치 옵션이 있는 iOS 브라우저에서도 같은 HTTPS 주소를 사용합니다.
6. 한투 실전용 키는 맥 관리자 화면이나 **소유자 패스키로 로그인한 휴대폰의 내 설정**에서 입력할 수 있습니다. 어느 화면에서 입력해도 키는 맥의 키체인에만 저장됩니다. 소유자 휴대폰은 시세, 보유 종목, 주문 상태를 표시합니다. 지인의 휴대폰에는 시세만 전달됩니다. 계좌와 주문, 한투 키 설정 권한은 소유자에게 있습니다. 패스키마다 개인 VIX 기준값을 저장할 수 있으며, 현재 매수 신호나 주문 계산에는 사용하지 않습니다. 패스키 등록 코드 발급·초기화, 버전 확인, 서버 종료는 맥 관리자 화면에서 처리합니다.

맥 관리자 화면의 패스키 목록에서 지인별 접근을 해제하거나 전체를 초기화할 수 있습니다. 기존 버전의 패스키는 소유자 권한을 유지하므로, 공유했던 패스키가 있다면 접근을 해제하고 시세 보기 권한으로 새로 초대하세요. 서버를 재시작하면 패스키 로그인 세션은 만료되며, 등록된 패스키는 보존됩니다. 지인에게 Tailscale 접근을 줄 때는 접근 정책에서 3Q 호스트의 HTTPS 포트만 허용하고, 관리자 포트나 맥의 다른 서비스에 대한 접근은 부여하지 마세요.

### 서버 업데이트

맥 관리자 화면의 **업데이트 확인**은 GitHub의 정식 버전 태그를 비교합니다. 새 버전이 있으면 장 마감 후 **내 설정 → 3Q 종료**를 누르고 같은 설치 명령에 새 태그를 지정하세요. 첫 설치 때 입력한 모바일 주소는 유지됩니다. 버전 변경 시 SQLite를 백업하며, 휴대폰은 같은 HTTPS 주소에서 새 화면을 사용하므로 다시 설치할 필요가 없습니다. GitHub 일반 커밋은 운영 버전을 변경하지 않습니다.

정식 태그를 게시하기 전 맥에서 개발 버전을 검증하려면 저장소에서 다음 명령으로 서버를 실행할 수 있습니다.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-mobile.txt
.venv/bin/python -m threeq live --mobile-origin https://맥의-실제-주소.ts.net
```

## 한투 공식 API 변경 확인

GitHub Actions의 **한투 API 변경 확인**은 매일 09:23 KST에 실행하도록 예약되어 있으며 수동 실행도 가능합니다. [한투 공식 저장소](https://github.com/koreainvestment/open-trading-api)의 기본 브랜치 최신 커밋을 검토된 기준 커밋과 비교합니다. 인증, 해외주식 시세·주문·잔고·체결 예제, 문서 및 종목 정보에 변경이 있으면 실패 상태로 표시하고 비교 링크와 파일 목록을 실행 요약에 남깁니다.

```bash
bash scripts/check-kis-upstream.sh
```

영향이 있는 API 계약을 검토하고 필요하면 3Q 구현과 테스트를 보완한 뒤 `scripts/kis-baseline.txt`를 검토한 커밋으로 바꿉니다. 한투의 예제 코드를 실행하거나 3Q의 배포 버전을 자동으로 변경하는 과정은 없습니다.

## 한국투자증권 실계좌

맥 관리자 화면 또는 소유자 패스키로 로그인한 휴대폰에서 **내 설정**을 사용합니다. 개발 중 터미널에서 직접 설정하려면 macOS에서 저장소 폴더를 열고 실행합니다.

```bash
python3 -m threeq configure-kis
python3 -m threeq live
```

첫 명령은 맥 터미널에서 실전용 앱 키, 앱 시크릿, 실계좌 앞 8자리, 상품코드 뒤 2자리를 순서대로 묻습니다. 입력은 화면에 표시되지 않으며, macOS 키체인의 `com.threeq.kis.production` 항목에 저장됩니다. 키를 재발급했으면 첫 명령을 다시 실행해 교체합니다. 키체인 접근 확인 창이 뜨면 실행한 Python의 접근을 확인한 뒤 허용하세요. 키체인에 저장하는 단계에서는 KIS 요청을 보내지 않습니다.

`THREEQ_KIS_APP_KEY`, `THREEQ_KIS_APP_SECRET`, `THREEQ_KIS_ACCOUNT`, `THREEQ_KIS_PRODUCT`로 설정하는 기존 방식도 지원합니다. 하나라도 설정되어 있으면 네 값이 모두 필요하며, 이때는 환경 변수가 키체인보다 우선합니다.

브라우저에서 `http://127.0.0.1:8033`을 열면 KIS 실계좌 보유 종목과 QQQ·TQQQ·SQQQ 최근 체결가, 3Q에서 제출한 주문의 접수·체결 상태를 확인할 수 있습니다. Discord 웹훅을 설정한 뒤 `live --discord`로 실행하면 확인된 전량 체결을 통지합니다. 시세는 REST를 순차 조회한 스냅샷이며 거래소 이벤트 시간이 포함된 1초봉은 별도 과제입니다. 실계좌 DB 기본 경로는 `~/Library/Application Support/3Q/live.sqlite3`입니다.

### 직접 확인한 지정가 주문

`python3 -m threeq order --help`에서 인자를 확인합니다. `order` 명령은 실제 증권사에 주문을 전송합니다. 매수·매도, 종목, 수량, USD 지정가, 주문당 한도, 당일 누적 한도를 직접 지정하고 `--confirm-live`를 붙여야 합니다. 한도는 해당 DB에서 3Q가 제출한 지정가 주문 금액 기준입니다. 대시보드에 KIS 접수가 표시되면 체결 조회가 확인될 때까지 후속 주문이 차단됩니다. 접수 번호를 받더라도 체결을 보장하지 않습니다.

응답이 끊어지면 자동 재전송하지 않습니다. KIS 앱에서 결과와 미체결 수량을 확인하세요. 미확인 접수의 주문번호를 찾으면 `resolve-order <로컬 ID> --verified-at-broker --broker-id <KIS 주문번호>`로 연결할 수 있습니다. 증권사에서 주문 없음 또는 잔여 주문 종료를 확정한 경우에만 `resolve-order <로컬 ID> --verified-at-broker --closed`를 사용합니다. 취소·정정은 KIS 앱에서 처리합니다. 뉴욕 평일 09:30~16:00 외에는 제출을 차단합니다. 휴장·조기폐장 및 주문 가능 여부는 KIS에서 확인해야 합니다.

구현에 사용한 API 계약은 [KIS 공식 해외주식 예제](https://github.com/koreainvestment/open-trading-api/blob/b0a0d33b7e5f863a8f3c6790f50adb840829c806/examples_user/overseas_stock/overseas_stock_functions.py)를 참고했습니다. 운영 투입 전 실계좌에서 조회 응답과 주문 대사를 검증하고, 자동화에 사용할 매매 규칙과 손실 한도를 확정해야 합니다. 현재 대시보드와 모니터에는 자동 주문 경로가 없습니다.

## 개발용 데모 실행

macOS 또는 Linux에서 Python 3.11 이상이 필요합니다. 별도 Python 패키지 설치 없이 저장소 디렉터리에서 시작합니다.

```bash
python3 -m threeq serve
```

브라우저에서 `http://127.0.0.1:8033`을 엽니다. 실행 중인 터미널을 유지하세요. 종료하려면 Ctrl+C를 누릅니다. 데이터와 계좌 상태는 기본적으로 `~/Library/Application Support/3Q/demo.sqlite3`에 저장됩니다. 새 모의계좌나 별도 포트는 `--db`와 `--port`로 지정할 수 있습니다.

대시보드에는 현재 포지션과 평가자산, 시세 지연, 최신 전략 판단, 최근 체결이 표시됩니다. 일시정지 버튼은 신규 모의 주문을 멈춥니다. 일시정지 중에도 시세는 저장되고 기존 포지션은 유지됩니다.

## 모의 전략

- QQQ의 연속 20초 가격 평균과 현재가를 비교합니다. 차이가 +0.1%를 넘으면 TQQQ, −0.1%보다 낮으면 SQQQ, 그 사이면 현금을 선택합니다.
- 방향이 바뀌면 기존 종목을 먼저 전량 매도하고, 새 종목은 주문 가능 현금의 최대 25%를 정수 주식 수로 매수합니다.
- 계좌는 $10,000에서 시작합니다. 한 초에 종목별 가격 샘플 1개를 저장합니다. 초가 누락되면 연속 샘플이 쌓일 때까지 주문을 보류합니다.
- 예시 규칙은 개발 검증용입니다. 모의 체결은 샘플 가격을 그대로 사용하며 수수료, 스프레드, 체결 지연을 반영하지 않습니다.

## Discord 모의 체결 알림

비공개 채널의 Incoming Webhook을 만들고, 환경 변수 `THREEQ_DISCORD_WEBHOOK`에 URL을 설정한 터미널에서 실행합니다. URL은 Git에 저장하지 않습니다.

```bash
python3 -m threeq serve --discord
```

데모 체결이 생기면 종목, 매수·매도, 수량, 체결가가 전송됩니다. 전송 결과가 불명확하면 중복 알림을 피하기 위해 자동 재전송하지 않습니다.

## CSV 리플레이와 테스트

리플레이는 별도 메모리 계좌에서 같은 전략을 실행해 샘플 수, 체결 수, 최종 평가자산, 누적 수익률, 최대 낙폭을 출력합니다. CSV 가격은 **USD 센트 정수**이며 시간은 오름차순의 시간대가 포함된 ISO 8601 초 단위로 지정합니다.

